## 🔗 创建目录传送门 v1.0.0

一个优雅的 Windows 右键菜单工具，让您像创建快捷方式一样，一键生成 NTFS 目录联接（Junction）。

### ✨ 功能特点

- **一键创建**：在文件夹上右键 → “创建传送门”，即可生成 Junction
- **智能安全**：自动阻止“指向自己”或“指向子目录”的危险操作
- **彩色界面**：ANSI 彩色输出，提示、警告、成功信息一目了然
- **自动提权**：自动请求管理员权限
- **自动定位**：创建成功后自动打开资源管理器并高亮显示

### 📦 版本说明

| 版本 | 文件 | 使用方式 |
|------|------|----------|
| 标准版 | `标准版（需加入右键菜单）.bat` | 添加到右键菜单后使用 |
| 便携版 | `便携版.bat` | 双击运行，手动输入目录 |

### 🚀 快速开始

#### 方式一：添加到右键菜单（推荐）
1. 下载 `标准版（需加入右键菜单）.bat`
2. 使用 HiBit Uninstaller 或注册表添加到右键菜单
3. 在任意文件夹上右键 → “创建传送门”

#### 方式二：便携版
直接双击运行 `便携版.bat`，按提示输入目录即可。
